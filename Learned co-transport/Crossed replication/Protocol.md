# Independent crossed replication of learned co-transport

The first experiment paired each new bend distribution with a different unseen teammate bank. This independent replication crosses both banks with both bend distributions. It tests whether the primary rotating-versus-fixed result survives genuinely new Q-learning runs and a broader combination of both evaluation factors.

Train all four focal arms and both opponent banks again using new seeds, with the same frozen state encoding, rewards, exploratory schedule and transition budgets. Use the earlier simulator without changes. Cross each of the two fresh opponent banks with each of the two test layout and noise distributions. Match base route, cue/slip uniforms, role assignment and frozen opponent IDs across focal methods within each cell. The four cells have fresh disjoint route seeds. Each cell uses 12 blocks, two roles and 128 routes per block per role. Both roles are pooled at equal weight. Pair the 12 training blocks across methods and do not treat the four cells as independent training runs.

The frozen primary comparison is completion with rotating versus fixed partner training, with the same longer observation history. Average the four cell effects within each block. Require a gain of at least 0.03 completion probability and a positive lower endpoint of a two-sided 95% paired bootstrap interval over those 12 block effects, using 10,000 draws. Individual cells, jam, reward, rotation with short history and the memory effect are secondary. Preserve all results and the earlier experiment. The method of assigning new partners and the basic environment are unchanged. The claim concerns this discrete payload model and these two test bank generators.
