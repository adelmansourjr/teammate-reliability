# Reliability in Shared-Load Coordination

Compares one-probe cooperation policies under fixed teammate marginals and a changed dependence structure.

Across 10,240 shared-load routes, reversing only the association between two teammate failure rates reversed which coordination prior performed best. The paired change in the prior advantage was 0.392 reward per route [95% interval 0.328, 0.457].
